Install tift

Download the archive for Windows, macOS, or Linux, extract it, and add the executable's directory to your PATH.

Download 0.2.1 ↓

For platform-specific setup, see the installation guide.

Install with Cargo

Requires Rust 1.99.1 or later.

cargo install tift --locked --registry crates-io

Preview formatting on changed lines

tift --diff --changed-since HEAD

Run tift . to format a project or tift --check . to check it in CI.
