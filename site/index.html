tift

A formatter for LaTeX and BibTeX

Indent LaTeX environments, format math, align equations and tables, and wrap prose while preserving verbatim content. Format, sort, and clean up bibliographies, and share a style across your projects, editor, and CI.

Install with Cargo

Requires Rust 1.99.1 or later.

cargo install tift --locked --registry crates-io

Preview a file

tift --diff main.tex

Run tift . to format a project or tift --check . to check it in CI.
